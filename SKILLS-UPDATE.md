# My Skill Universe update

This update improves the existing Skills section without changing the app architecture or global visual identity.

- Interactive category rail with selected state and arrow-key navigation.
- Skill cards with contextual accent lighting, active indicators, hover/focus selection, and staggered entrance motion.
- Selected-skill detail panel showing only project associations already present in `src/data/portfolio.ts`.
- Reduced-motion support and visible keyboard focus states.
- Responsive layout retained, including horizontal category navigation on smaller screens.

Run `npm ci` and `npm run build` to build the project.
